# cv_course

## Комментарий к лекциям

Я использовал [slidev](https://sli.dev/) для создания слайдов. В каждой папке вы найдете файл **slides.md** и (опционально) папку **imgs/** для графики. 

Вам необходимо создать шаблон презентации:

```bash
npm slidev init
```

и заменить в созданной директории файл **slides.md** на тот, который соответствет лекции, а также скопировать папку **imgs/** в созданную директорию (в базовом шаблоне её нет).

После можно будет запустить отображение материала в виде html-странички

```bash
npm run dev
```

## Комментарий к практикам

Я использовал [uv](https://docs.astral.sh/uv/) для создания окружения. В каждой папке вы найдете файл **pyproject.toml** с зависимостями. 

Вам необходимо сформировать окружение:

```bash
uv sync
```

После этого можно будет запустить jupyterlab:

```bash
uv run jupyter-lab
```
